# AI Agent

Mastra AIフレームワークを使用したAIエージェントアプリケーション。

## セットアップ

```bash
bun install
```

## 開発

```bash
moon run ai-agent:dev
```

## ビルド

```bash
moon run ai-agent:build
```

## 機能

- Weather Agent: 天気情報を取得するエージェント
- Weather Workflow: 天気情報処理ワークフロー
- LibSQL Store: テレメトリと評価データの保存
- Pino Logger: ロギング機能
